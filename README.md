# Agentic DevOps Platform

An open-source reference implementation for policy-driven,
AI-assisted cloud infrastructure deployment.

## Vision

Agentic DevOps combines AI-assisted infrastructure automation,
Infrastructure-as-Code, security policies, governance and
continuous observability.

The goal is to move from:

Infrastructure-as-Code

to:

Infrastructure Intelligence.

## Architecture

       ↓

## Current Capabilities

- Terraform-based Azure infrastructure
